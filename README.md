# Project 1: Complete E-commerce case

完整电商系统 + 秒杀模块（全栈学习项目）

## 项目简介
一个纯本地的前后端分离电商平台，包含用户端商城、商家后台、平台管理后台，并嵌入高并发秒杀模块。
本项目以巩固全栈知识为目标，覆盖安全、数据库设计、测试、工程化、性能压测、前端工程化等知识点。

## 技术栈
- 前端：Vue 3 + TypeScript + Vite + Pinia + pnpm + Element Plus
- 后端：Spring Boot + MyBatis-Plus + MySQL + Redis + RabbitMQ
- 测试：JUnit + Mockito ｜ 压测：k6
- 版本控制：Git

## 角色
- 用户（买家）
- 商家（卖家）
- 系统管理员（平台）

## 主要功能
- 用户端：注册登录、商品浏览/搜索、购物车、下单、模拟支付、订单、优惠券、评价、收藏
- 商家后台：商品管理、库存管理、订单管理
- 平台后台：用户/商家管理、分类管理、秒杀活动配置、全局订单
- 秒杀专场：限时限量、倒计时、高并发防超卖
